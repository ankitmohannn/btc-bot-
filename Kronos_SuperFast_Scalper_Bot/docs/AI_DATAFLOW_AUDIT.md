# AI Dataflow & Intelligence Architecture Audit

## Executive Summary
This document provides a forensic audit of the dataflow, machine learning heuristics, and research integrations between MetaTrader 5 (`SmartScalper_V2.mq5`) and the Python AI Bridge (`ai/bridge/`).

The audit specifically addresses the 8 mandatory compliance questions regarding the true nature of the AI layer.

---

## 1. Forensic Audit Questions & Verified Answers

### Q1: Is an actual ML model being used?
**Answer: NO.**  
The live execution bridge currently uses a deterministic, rule-based scoring heuristic (`vibe_trading_adapter.py`) that scores trend alignment, RSI/ADX momentum, and SMC structure IDs. There is no weights-trained neural network (e.g. PyTorch/TensorFlow) or gradient-boosted tree (e.g. XGBoost/LightGBM) actively inferencing on live ticks.

### Q2: Is an LLM being used?
**Answer: NO.**  
No Large Language Model (LLM) is used for real-time tick execution. Scalping sub-second ticks using LLMs would introduce latency ($>1,500\text{ms}$) and nondeterministic hallucinations. LLMs and HKUDS Vibe-Trading natural language agents are confined strictly to offline research, strategy hypothesis generation, and post-trade journal analysis.

### Q3: Is Vibe-Trading being used only for research?
**Answer: YES.**  
HKUDS Vibe-Trading is utilized as an offline research and attribution engine (`research_evaluator.py`). It ingests historical trade journals (`smart_scalper_journal.csv`), calculates statistical metrics (Profit Factor, Sharpe, MAE/MFE), performs 1,000-iteration Monte Carlo stress testing, and formulates candidate parameter hypotheses. Live order gatekeeping remains 100% deterministic inside MQL5.

### Q4: Is the confidence score deterministic?
**Answer: YES.**  
The confidence score output by `vibe_trading_adapter.py` is calculated via explicit deterministic arithmetic:
- EMA fan bullish alignment ($+25\%$)
- Close > 200 EMA ($+15\%$)
- Bullish momentum expansion ($+20\%$)
- BOS/CHoCH/Sweep structure confirmation ($+25\%$)
- Spread $\le 30\text{ points}$ ($+15\%$)
Given identical inputs, the output confidence is 100% mathematically reproducible.

### Q5: What inputs generate AI confidence?
**Answer:**  
The inputs are strictly derived from the `FeaturePacket` emitted by MT5:
1. `symbol`
2. `timestamp`
3. `bid` / `ask` / `spread`
4. `open` / `high` / `low` / `close`
5. `volume`
6. `atr` (14-period)
7. `rsi` (14-period)
8. `adx` (14-period)
9. `ema9`, `ema20`, `ema50`, `ema200`
10. `regime_id` (0 to 10)
11. `structure_id` (1=BOS Bull, 2=BOS Bear, 3=CHoCH Bull, 4=CHoCH Bear, 5=Sweep BSL, 6=Sweep SSL)
12. `recent_win_rate` and `consecutive_losses`

### Q6: Is confidence trained or calibrated?
**Answer: NOT FORMALLY TRAINED.**  
The weights in `vibe_trading_adapter.py` are expert-calibrated institutional rule weights, not parameters derived from gradient descent optimization.

### Q7: Does AI see any information unavailable to the MT5 engine?
**Answer: NO.**  
The AI bridge receives only features generated by MT5 on closed candles and current bid/ask prices. It does not possess proprietary external order book data or alternative datasets that MT5 does not provide.

### Q8: Could any input introduce future information (Lookahead Bias)?
**Answer: NO.**  
- All moving averages, RSI, ADX, and ATR values are calculated on current and historical bars.
- Market structure events (BOS, CHoCH, Sweeps, FVG) are strictly evaluated on closed bars ($\text{Bar } \ge 1$).
- No future candle data, future zigzag pivots, or subsequent price moves are accessed.
